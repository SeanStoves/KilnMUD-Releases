# KilnMUD Releases

Downloads for [KilnMUD](https://github.com/SeanStoves/KilnMUD), a cross-platform MUD client built on Tauri 2.

Grab the latest build for your platform from the [Releases](https://github.com/SeanStoves/KilnMUD-Releases/releases) page.

Current builds are unsigned daily-driver prereleases; your OS may warn on first launch.
